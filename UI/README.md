# V60
 
A simple page that shows a robot arm pouring water on coffee.
 
You choose how long each pour is, and how long to wait between pours. Then you press Start.
 
This is a test version. It is not connected to a real machine yet.
 
## Files
 
- `index.html` – the page
- `style.css` – the colors and look
- `script.js` – makes it work
## How to open
 
1. Put the 3 files in one folder.
2. Open `index.html` in your browser.
## How to use
 
1. Set how long Pour 1 is.
2. Press **+ Add pour** to add another pour.
3. For each new pour, set the wait time and how long it pours.
4. Press **Delete last pour** to remove the last one.
5. Press **Start brew**.
## Good to know
 
- Each time can be from 5 to 60 seconds. Wait time can be from 0 to 60.
- You can add up to 12 pours.
- You cannot change anything while it is brewing.
